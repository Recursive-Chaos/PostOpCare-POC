# PostOpCare Web Dashboard
Dashboard-ul pentru medici. Facut cu Next.js si TypeScript.

## Cum il pornesti

1. Intra in folder: `cd web`
2. Instaleaza ce trebuie: `npm install`
3. Porneste: `npm run dev`

Dashboard-ul ruleaza pe: `http://localhost:3000`

## Ce e prin foldere

- `src/app/page.tsx` -> Pagina principala
- `src/app/layout.tsx` -> Layout-ul comun (ce apare pe toate paginile)
